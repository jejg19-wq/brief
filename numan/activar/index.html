Encender el sistema y hacer la prueba real

Los pasos exactos para pasar de demo a generar renders, videos y tours de verdad — y producir el material de muestra con un proyecto que ya tienen.

⏱ 25 minutos en total

Parte 1 — Encender el sistema

1

Cuenta en fal.ai

10 min
  1. Entra a fal.ai y haz Sign up (sirve tu cuenta de Google).
  2. Ve a Billing → agrega la tarjeta → recarga $20 de saldo (alcanza de sobra para toda la prueba y los primeros clientes).
  3. Ve a Dashboard → Keys → Create key → cópiala.
Importante: esa clave es como la tarjeta de crédito del sistema. No la pegues en WhatsApp ni en ningún chat — en el paso 2 la escribes tú directo en Vercel y ahí queda guardada de forma segura.
2

Publicar la app en Vercel

10 min · gratis
  1. Entra a vercel.com → Sign up → Continue with GitHub (con tu cuenta jejg19-wq).
  2. Add New → Project → busca el repositorio brief → Import.
  3. Antes de darle Deploy, llena estos campos:
Root Directoryclic en Edit y elige la carpeta arqviz
Environment Variables → KeyFAL_KEY
Environment Variables → Valuetu clave de fal.ai
  1. Presiona Deploy y espera 1–2 minutos.
  2. Al terminar, ve a Settings → Git → Production Branch, escribe claude/architect-blueprint-3d-app-ik0ka2 y guarda. Luego Deployments → Redeploy.
Ese último paso importa: ahí es donde vive el código de la app. Si lo saltas, Vercel publica el sitio viejo del brief en vez del estudio 3D.
3

Comprobar que quedó viva

5 min
  1. Abre la URL que te dio Vercel (algo como brief-xxxx.vercel.app).
  2. Si ya no aparece la barra de "Modo demo", está en modo real. ✅
  3. Crea un proyecto, sube cualquier plano y genera 1 solo render.
  4. Ese primer render de $0.15 es la prueba de fuego de todo el sistema.
Cuando salga: pásame la URL de Vercel y verifico que todo esté fino antes de arrancar la producción del cliente.

Parte 2 — La prueba con el cliente viejo

4

Qué necesito del proyecto

Elijan un proyecto ya terminado y bonito — mientras mejor se vea, mejor vende. De ese proyecto suban a la carpeta de Drive:

  1. El plano en imagen (JPG o PNG; si está en PDF, una captura sirve).
  2. Vistas del modelo SketchUp: 1–2 por ambiente + una aérea sin techo. Si no las tienen a mano, con el plano solo también arrancamos.
  3. Fotos reales del sitio (si la obra existe): fachada, calle y la vista desde el balcón o ventanas. Esto es lo que hace el efecto "esa es mi casa".
  4. El estilo que quieren mostrar: moderno, minimalista, clásico… con una nota de voz basta.
Con eso produzco: renders de cada ambiente + video recorrido Seedance 2.5 + tour 360° + el enlace privado con marca — o sea, exactamente lo que promete la cotización, pero hecho de verdad.
5

El paquete de venta

Al cliente nuevo le llegan dos cosas juntas: la cotización Decostone (los 3 servicios + el Paquete Completo a $2.700) y el enlace del trabajo real que hicimos con el proyecto viejo. Ve la cotización y de inmediato puede tocar el link y caminar por una casa terminada. Eso es lo que cierra la venta.
